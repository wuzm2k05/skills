# 图书比价答复口径（属性解析 / 渠道说明）

交付任何图书比价、优惠券、买书推荐回复前，必须按本文件逐项核对。

## 1. 数据强绑定（1 行 = 1 条原始记录）
- 表格中每一行的 **平台、店铺、出版社/装帧、类型（全新/二手）、价格、goodsId、购买方式**，必须严格对应同一条 `search` 返回结果及该记录调用的 `detail` 输出。严禁把 A 记录的价格与 B 记录的链接拼成一行。
- **价格表达**：
  - 核心展示 `actualPrice`（券后价/到手参考价）。
  - 若包含大额优惠券，需标注“原价 ¥X，领 ¥Y 券后到手 ¥Z”。
  - 无法确定是否有额外促销（如满减、PLUS 会员）时，统一标注“以平台页面结算为准”。

## 2. 图书属性提取与版本分类
从商品 `title` 中智能识别并标注以下属性：
- **版本类型划分（必须高亮区别）**：
  - **【全新正版】**：常规新品图书。
  - **【二手/旧书】**：标题含“二手”、“九成新”、“旧书”等，必须在“类型”栏明确标注，**不得与全新书混在同一表格中简单比价**。
  - **【电子书/资源】**：标题含“PDF”、“电子版”、“网盘”等，必须标注。
- **关键属性提取**：
  - **出版社**：如“机械工业出版社”、“清华大学出版社”。标题未写则标注“未注明”。
  - **装帧形式**：精装 / 平装。
  - **册数规格**：单本 / 全套N册 / 1-3卷。

## 3. 渠道覆盖与当当网说明
- 响应“哪里买最便宜”或“全网比价”时，需列出实际查询过的渠道（如京东自营、天猫、拼多多等）。
- 若某个渠道未查到数据，需说明“X 平台未检索到相关现货/记录”。
- **当当网特别说明**：当用户明确询问当当网价格时，统一提示：“已为您自动比对当当网在天猫及拼多多官方旗舰店的实时报价。”

## 4. 结论与价格边界
- **可信度提示**：若发现远低于正常市场价的链接，提示用户“价格偏低，请注意核对是否为盗版、二手或影印版”。
- **比价结论**：若主要渠道均查有数据，可说明“在本次查询到的记录中，全新正版最低为 ¥X（平台/店铺）”；若有主流渠道未覆盖，需补充“未覆盖 X 渠道，结果仅供参考”。

## 5. **渠道未授权/拿不到链接处理**：
  - 淘宝/天猫 或拼多多等渠道可能因第三方平台账号未绑定授权而返回错误或无法生成转链：
  - 遇到未授权渠道时，必须在回复中如实说明：“【X 平台】接口未授权绑定，暂时无法提取直达购买链接”。
  - 自动退守展示已授权且能正常获取链接的平台（如京东），并遵守边界规则，提示“由于部分渠道未授权，本次比价结果仅覆盖部分平台”。

## 5. 必附数据来源声明（结尾粘贴）
> 数据来源：第三方聚合平台，查询无需登录用户账号；图书价格、库存与优惠券实时变动，仅供购物参考，最终价格以各平台实际下单页面为准。
